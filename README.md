# Timespinner WASM

A web port of [Timespinner](https://store.steampowered.com/app/368620/Timespinner/).

**Play:** [https://agentcube.github.io/timespinner-wasm](https://agentcube.github.io/timespinner-wasm)

## Controls

### In-Game Controls

| Action | Primary Key |
| --- | --- |
| Movement (Left / Right) | `Left` / `Right` Arrow Keys |
| Duck / Crouch | `Down` Arrow Key |
| Look Up | `Up` Arrow Key |
| Jump | `Spacebar` |
| Primary Melee / Orb Attack | `Q` |
| Secondary / Spell Attack | `W` | 
| Dash / Forward Dash | `R` |
| Backdash / Dodge | `D` |
| Time Stop (Time Spinner) |
| Pause Game | `Escape` or `Enter` |

### Menu Controls

| Action | Key |
| --- | --- |
| Navigate Options | Arrow Keys |
| Confirm / Select | `Enter`, `Spacebar`, or `Q` |
| Cancel / Back | `Escape`|
| Switch Tabs / Pages | `Tab` or `D` / `R` |
